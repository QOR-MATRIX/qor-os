# services — contracts and QTOS.Services

| Path | Contents |
|------|----------|
| `interfaces/*.rep` | Qt Remote Objects contracts: `network`, `bluetooth`, `power`, `audio`, `display`, `media`, `notifications`, `settings`, plus the simulation-only `simcontrol` |
| `qml/services.h/.cpp` | `qtos::Services`, the QML singleton holding typed replicas; `connectTo(url)`; QML type info (`*ServiceForeign`) |
| `qml/Intents.qml` | App → system requests (`app.open`, `session.lock`, `shell.*`) |

Replicas are generated by `qtos_add_repc_replicas()`
([`cmake/QtosRepc.cmake`](../cmake/QtosRepc.cmake)) so AUTOMOC produces the
metatypes QML tooling needs. Sources are generated in [`sim/`](../sim/).

Reference and usage: [docs/SERVICES.md](../docs/SERVICES.md).
