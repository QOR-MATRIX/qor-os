# Code of conduct

QOR OS adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
as its code of conduct.

In short: be respectful, assume good intent, give and accept constructive
feedback gracefully, and focus on what is best for the project and the people
working on it. Harassment, discrimination and personal attacks are not
tolerated in any project space: issues, pull requests, reviews, discussions
or chat.

## Reporting

Report unacceptable behaviour privately to the repository maintainers through
[GitHub](https://github.com/QOR-MATRIX/qor-os/security/advisories/new) (mark the
report as a conduct issue), or directly to an organisation owner of
QOR-MATRIX. All reports are handled confidentially.

## Enforcement

Maintainers follow the Contributor Covenant
[enforcement guidelines](https://www.contributor-covenant.org/version/2/1/code_of_conduct/#enforcement-guidelines):
correction, warning, temporary ban, permanent ban, depending on severity.
